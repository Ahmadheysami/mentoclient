# Frontend Performance

Optimize based on actual or technically justified bottlenecks.

Inspect when relevant:

- bundle size
- lazy loading
- rendering
- reactivity
- network requests
- duplicated requests
- images
- hydration
- memory

Do not optimize blindly.

Do not sacrifice correctness or maintainability for insignificant gains.
