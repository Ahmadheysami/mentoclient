# Security Review

Perform a focused frontend security audit.

Check:

- XSS
- unsafe HTML
- authentication
- authorization assumptions
- token handling
- storage
- cookies
- redirects
- sensitive data
- API responses
- user input

## Severity

CRITICAL
HIGH
MEDIUM
LOW
INFO

Do not inflate severity.

For each finding provide:

Location
Problem
Impact
Evidence
Remediation

Finish with:

SECURITY_GATE: PASS

or:

SECURITY_GATE: BLOCKED
