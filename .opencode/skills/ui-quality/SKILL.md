# UI Quality

Evaluate the interface as a production product.

## Visual Quality

Check:

- hierarchy
- spacing rhythm
- typography
- alignment
- density
- consistency
- visual balance

## Interaction Quality

Check:

- hover
- focus
- active
- disabled
- loading
- success
- error
- empty

## UX Quality

Ask:

- Is the primary action obvious?
- Can the user understand the page without explanation?
- Are errors actionable?
- Are destructive actions clear?
- Is feedback immediate?

## Polish

Look for:

- awkward spacing
- inconsistent sizing
- visual noise
- unnecessary borders
- excessive shadows
- inconsistent icons
- awkward animations

## Final Rule

Do not add visual effects simply to make the UI look impressive.

Every visual element must support hierarchy, usability or brand.
