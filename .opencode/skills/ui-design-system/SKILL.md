# UI Design System

Build interfaces using a consistent visual system.

## Before Creating UI

Inspect:

- existing design tokens
- colors
- typography
- spacing
- radius
- shadows
- buttons
- inputs
- cards
- dialogs
- navigation
- existing layout components

Reuse existing components before creating new ones.

## Visual Hierarchy

Every screen should have:

1. Primary action
2. Clear heading hierarchy
3. Logical grouping
4. Consistent spacing
5. Predictable interaction

## Avoid

- random colors
- excessive gradients
- excessive shadows
- inconsistent border radius
- unnecessary animations
- visually noisy layouts
- arbitrary spacing

## Components

Prefer reusable components for repeated patterns.

Do not create abstractions for one-time elements unless complexity justifies it.

## Quality

The UI should feel:

- intentional
- consistent
- modern
- responsive
- accessible
- production-ready
