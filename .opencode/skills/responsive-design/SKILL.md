# Responsive Design

Design for real content, not fixed screenshots.

## Consider

- mobile
- tablet
- desktop
- large screens
- small screens
- long text
- dynamic content
- empty states

## Rules

Prefer fluid layouts.

Avoid:

- fixed widths when unnecessary
- viewport-specific hacks
- duplicated layouts without justification

Use existing project breakpoints.

## Test

Check:

- navigation
- forms
- tables
- cards
- dialogs
- overflow
- typography
- touch targets
