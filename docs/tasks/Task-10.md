# [Phase-1 (Test ai analysis)]

## [Task-Overview]

### تحلیل آزمون انجام شده با هوش مصنوعی

در صفحه 'نتایج آزمون' در همه app در صفحه single هر آزمون در صفحه '@app/pages/test/done/[id].vue' و در همه صفحات اینشکلی در app باید یک دکمه 'تحلیل نتیجه با هوش مصنوعی' اضافه شود

نکته: زمانی که نتایج از api دریافت میشوند  به هر کدام از نتیجه ها یک ویژگی به نام aiAnalysis افزوده شده که اگر وجود داشته باشد و پر باشد یعنی تحلیل با هوش مصنوعی انجام شده

حالا کاربر نتیجه را میتواند ببیند در غیر اینصورت دکمه 'تحلیل نتیجه با هوش مصنوعی' به کاربر نمایش دادهشود 
و اگر تحلیل انجام شده کاربر میتواند تحلیل مجدد با پرداخت هزینه مجدد انجام دهد

برای تحلیل از api زیر استفاده میشود

> /.api/test/result-with-ai?refresh=false

body: 

```json
"id": "string" // id property from result item
```
نکته: در query=refresh مقدار boolean میگیرد و حالت دیفالت false میباشد اگر یک بار آزمون انجام داده یاشد و نتیجه ذخیره شده باشد میتواند با پرداخت هزینه مجدد دوباره تحلیل انجام دهد و این تحلیل جایگزین تحلیل قبلی شود

response:

نکته:‌ برای نمایش قیمت تحلیل با هوش مصنوعی زمانی که وارد صفحه single هر نتیجه میشویم با استفاده از api زیر که. در store مربوط به test.ts در پوشه stores نوشته شده اطلاعات را دریافت میکنیم و اگر ویژگی  analysisAiEnabled برابر true بود یعنی این آزمون دارای قابلیت تحلیل با هوش مصنوعی میباشد و گزینه ها و دکمه ها را برای کاربر نمایش بده در غیر اینصورت تحلیل با هوش مصنوعی را قرار نده

نکته: در هنگام دریافت @app/components/test/Single.vue یک badge اضافه کن اگر آزمون تحلیل با ai داشته باشد عنوان 'تحلیل با هوش مصنوعی فعال است ' را قرار بده در غیر اینصورت چیزی قرار نده 

اگر در نهایت در هر یک از قسمت ها analysisAiEnabled فعال باشد ویژگی قیمت یعنی analysisAiPrice را قرار بده

# [Phase-4  (DISC test chart result)]
برای آزمون های DISC یک نمودار میله ای شخصی سازی شده و زیبا و سه بعدی طراحی شود

در آزمون disc باید نمودار های لازم را لود کنیم

سه نمودار داریم که در اول صفحه single نمایش هر نتیجه ظاهر میشود

4 ستون قرار داده میشود

D: قاطع
I: اجتماعی
S: حمایت گر
C: تحلیل گر

سه نمودار میله ای خواهیم داشت که در rawScore به شکل ذخیره میشود 

ما باید نمودار ها را به شکل زیر قرار بدهیم

1_ نمودار کمترین شباهت
2_ نمودار بیشترین شباهت
3_ میانگین و نتیجه نهایی

که هر کدام به شکل 

```typescript
// اعداد بین ۰ تا ۷ میباشد
interface RawStructure {
  D: number;
  I: number;
  S: number;
  C: number;
}
```

**نکته:‌ این موارد فقط در آزمون DISC و در صفحه نتیجه ها میباشد یعنی در آدرس @app/pages/test/done/[id].vue میباشد**

# [Phase-5 (Carousel)]

در کامپوننت Carousel.vue باید به عنوان prop یک ویژگی به نام for بگیریم

و بعد به api زیر که در swagger موجود است درخواست بزنیم

> /.api/ui/carousel/{for}

for یک کلید است که در بک اند شناسایی میشود و carousel ها را میگرد

میتوانی در پوشه Server این api را بخونی تا بدانی در خروجی چه بر میگرداند
